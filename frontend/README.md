# 实习路径：本机页面

这是 React + Vite 单页界面，连接项目根目录的 FastAPI 后端。页面依次完成个人画像、岗位解读、匹配判断和求职记录。

在 macOS 上，最简单的启动方式是双击项目根目录的 `start_local.command`，保持打开的终端窗口运行。它会同时启动前后端并打开浏览器。关闭窗口或按 Control-C 后服务停止；下次启动需重新在页面输入 DeepSeek Key。

在项目根目录启动后端：

```bash
.venv/bin/uvicorn src.backend.api:app --host 127.0.0.1 --port 8000
```

在 `frontend/` 目录启动页面：

```bash
npm install
npm run dev -- --host 127.0.0.1
```

打开 `http://127.0.0.1:5173/`。开发服务器把 `/api` 转发到本机后端，页面代码不包含模型 API Key。

首次使用时，在页面右上角点“模型设置”，把 DeepSeek API Key 输入密码框并点“在本机设置 Key”。Key 只保存在本机后端当前进程的内存中，服务停止后会清除；页面和接口不会显示原文。也可选择在启动后端的终端设置 `DEEPSEEK_API_KEY` 环境变量。

用户勾选同意后，脱敏的简历文字或结构化画像才会发给所选模型服务商。分析草稿要由用户核对并确认，之后才保存到本地 SQLite；没有自动投递。页面视觉参考了用户提供的岭南学院就业指导系统截图中的酒红顶栏、搜索区和岗位卡片，但本项目是独立研究原型，不使用学院的官方标识。
